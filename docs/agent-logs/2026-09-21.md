## Session Entry 3 — Comprehensive Form Controls Disabling During Execution and Dynamic QUEUED Row Status Badge

**Time:** ~21:45 WIB  
**Branch:** `task/dual-mode-ui`  
**Commit:** `HEAD` (`fix(hud): enforce comprehensive form disabling during execution and add queued row status badge`)  
**Product code changed:** YES (`src/overlay/CustomSelect.js`, `src/overlay/FlowHUDHost.js`, `src/overlay/FlowHUDTemplates.js`, `src/overlay/overlay.css`)  
**Pushed:** NO  

### What Was Done
- **Root Cause Analysis:**
  - Evaluated reported bug where only `Model Selector` was visually disabled while other controls remained interactive during queue execution.
  - Identified two underlying issues:
    1. In `FlowHUDHost.js`, `setFormControlsDisabled` queried `selMode` instead of `selGenerationMode` (element ID mismatch), and invoked `CustomSelect.sync()` which was not defined in `CustomSelect.js` (only `refresh`), resulting in an uncaught `TypeError` that aborted subsequent disabling logic before it reached toolbar buttons, textareas, or segment groups.
    2. Shadow DOM CSS lacked explicit disabled rules for `.rj-select-wrapper.disabled`, `.row-prompt-input:disabled`, `.row-select-checkbox:disabled`, and `.rj-segment-group.is-disabled`.
- **Comprehensive Form Control Disabling During Execution:**
  - `src/overlay/CustomSelect.js`: Added `static sync(selectEl)` alias pointing to `CustomSelect.refresh(selectEl)`.
  - `src/overlay/FlowHUDHost.js`:
    - Updated `setFormControlsDisabled(disabled)` to query `#selGenerationMode` and refresh all custom dropdowns (`#selGenerationMode`, `#selModelFamily`, `#selResolution`, `#selParamMode`).
    - Disables select-all checkbox (`#chkSelectAllQueue`), sort button (`#btnToggleSortMode`), add row button (`#btnAddQueueRow`), and bulk delete button (`#btnBulkDeleteQueue`).
    - Disables segmented button groups (`#segDuration`, `#segAspectRatio`, `#segOutputs`) and their individual buttons.
    - Disables all row checkboxes (`.row-select-checkbox`) and prompt textareas (`.row-prompt-input` via `disabled = true`, `readOnly = true`, and classes `.is-disabled`, `.is-readonly`).
    - Added running guard checks (`if (this.isRunning) return;`) to all sidebar parameter change listeners (`selModelFamily`, `selResolution`, `btnSaveQueue`, segmented buttons).
    - Preserved row container selection/unselection: Clicking a row container during execution allows toggling focus (`activeRowIdx`) to inspect parameters in the sidebar in read-only mode, and unselecting when clicking an already focused row, while strictly enforcing `setFormControlsDisabled(true)`.
    - Hardened `updateSelectionUI()` to retain disabled states on `#chkSelectAllQueue`, `#btnToggleSortMode`, and hide `#btnBulkDeleteQueue` while running.
  - `src/overlay/overlay.css`:
    - Added `.row-prompt-input:disabled` and `.row-prompt-input.is-disabled` styling (`opacity: 0.55 !important; cursor: not-allowed !important; background-color: #121314 !important; border-color: rgba(255, 255, 255, 0.05) !important;`).
    - Added `.row-select-checkbox:disabled`, `.row-select-checkbox.is-disabled`, `.rj-checkbox:disabled` styling (`opacity: 0.35 !important; cursor: not-allowed !important; pointer-events: none !important;`).
    - Added `.rj-select-wrapper.disabled` and `.rj-select-trigger` styling for custom select wrappers in Shadow DOM.
    - Added `.rj-segment-group.is-disabled` styling (`pointer-events: none !important; opacity: 0.45 !important;`).
- **Dynamic QUEUED Row Status Badge During Batch Execution:**
  - When batch execution is active (`this.isRunning === true`), pending rows with valid prompts and media waiting in the queue display the badge `QUEUED` with class `.status-queued` instead of `READY`.
  - Upon stopping, pausing, or completing the queue, remaining ready rows seamlessly revert to `READY`.
  - `src/overlay/FlowHUDTemplates.js`:
    - Updated `getRowStatusInfo(item, mode, isRunning)` to accept `isRunning` and return `{ label: 'QUEUED', statusClass: 'status-queued' }` when `isRunning || rawStatus === 'queued'`.
    - Updated `renderQueueRow` signature to pass `isRunning` to `getRowStatusInfo`.
  - `src/overlay/overlay.css`:
    - Added `.row-status-badge.status-queued` styling (`background-color: rgba(148, 163, 184, 0.14); color: #94a3b8; border: 1px solid rgba(148, 163, 184, 0.25)`).
  - `src/overlay/FlowHUDHost.js`:
    - Triggered `this.updateAllRowBadges()` inside `onStateChange` (on RUNNING, STOPPED, and IDLE) and `onProgress` so waiting rows dynamically transition between `READY` and `QUEUED`.
    - Passed `this.isRunning` to `getRowStatusInfo` across `updateRowBadges()`, `renderQueueContent()`, `updateStartButtonState()`, and `updateQueueSummaryUI()`.
- **Verification:**
