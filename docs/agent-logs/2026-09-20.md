### What Was Done
- **Issue 1: Focus Toggle on Row Container Click (Kondisi Pertama, `src/overlay/FlowHUDHost.js`):**
  - Refactored single container click logic: when 0 rows are checked and a row is clicked, it becomes focused (`this.activeRowIdx = idx`, `.row-active` cyan accent) without checking the checkbox.
  - Clicking the same row container a second time toggles off focus (`this.activeRowIdx = null`), completely removing `.row-active` and returning the row to neutral un-focused state.
- **Issue 2: Transition from Single Focus to Multi-Select (Kondisi Kedua, `src/overlay/FlowHUDHost.js`):**
  - Normal click when 0 rows are checked switches active focus between rows cleanly without checking any checkboxes.
  - When row A (e.g. row 2) is focused without checkmark, `Ctrl` / `Cmd` + clicking container row B (e.g. row 3) now checks both row A and row B (`selected = true`). Seamlessly transitions into multi-selection mode using standard desktop modifier keys without requiring precise checkbox clicks.
- **Issue 3: Unchecking Focus Clearing & Active Row Shift (`src/overlay/FlowHUDHost.js`):**
  - Fixed bug where unchecking row 2 left it in active focus state (`.row-active` cyan border) shown in user screenshot.
  - When unchecking a row (either via direct checkbox click or clicking container of an already checked row):
    - The row loses both checkmark (`selected = false`) and focus.
    - If another checked row remains (e.g. row 3), active focus shifts to that remaining checked row (`this.activeRowIdx = remaining`).
    - If no checked rows remain, `this.activeRowIdx` resets to `null`, completely clearing `.row-active` across all rows, hiding the trash icon, and reverting the Single mode sidebar to `#sidebarSinglePlaceholder`.
- **Issue 4: Active Row Trash Button Visibility & Deletion (`src/overlay/FlowHUDHost.js`):**
  - In `updateSelectionUI()`, set `#btnBulkDeleteQueue` visibility to `hasSelectionOrActive = selectedCount > 0 || (this.activeRowIdx !== null && Boolean(this.queueItems[this.activeRowIdx])) ? 'inline-flex' : 'none'`.
  - In `#btnBulkDeleteQueue` click handler, if `selectedCount === 0` but a single row is active/focused via container click, clicking the trash button deletes that active row directly and resets `activeRowIdx = null`.
  - When no rows are checked and no rows are focused, the trash button is strictly hidden.

### What Was Done
- **Issue 1: Row Container Click vs Checkbox Click Multi-Select Logic (`src/overlay/FlowHUDHost.js`):**

    - **When 0 items are checked (`selectedCount === 0`)**: Clicking a row container focuses/activates that row (`this.activeRowIdx = idx`, applying `.row-active` cyan accent highlight) **without checking its checkbox** (`it.selected = false`). In Single Mode, sidebar controls display parameters for this active row (`ROW #X`) with clamped prompt preview, enabling instant parameter inspection and editing without checking any checkboxes. Checkboxes remain strictly unchecked across both Batch and Single modes.
    - **When 1 or more items are already checked (`selectedCount > 0`)**: Clicking any other row container automatically checks that row too (`it.selected = true`, "ikut kecentang"), adding it to the multi-selection set without requiring the user to aim precisely at the 16px checkbox.
    - **Direct Checkbox Click**: Clicking the `.row-select-checkbox` directly (`change` event with `e.stopPropagation()`) continues to toggle individual row selection independently without deselecting other checked rows.

    - **Parameter Modifications**: In Single mode, changes to mode, model, duration, aspect ratio, outputs, and resolution apply to all checked rows (`selected.length > 0`) or fall back to the active focused row (`this.activeRowIdx !== null`).
- **Issue 2: Strict Conditional Trash Icon Hide (`src/overlay/FlowHUDHost.js`):**
  - Fixed regression where `#btnBulkDeleteQueue` remained visible in Single mode when no rows were checked (previously caused by `(this.paramMode === 'single' && this.activeRowIdx !== null)`).
  - In `updateSelectionUI()`, strictly enforced `btnBulkDelete.style.display = selectedCount > 0 ? 'inline-flex' : 'none';`. The trash button is now completely hidden whenever 0 rows are checked, in both Single and Batch modes.
  - In `#btnBulkDeleteQueue` click handler, strictly enforced `toDelete.length === 0 return;` targeting only items where `it.selected === true`.
