### What Was Done
- **Multi-Language Forensic Audit (Indonesian Locale `id-ID`):**
  - Audited `rekaman-google-flow-20260922_235944.json` and `dev-tools/recordings/log plus script inject.md` generated on a system set to Indonesian (`id-ID`).
  - Identified the exact root cause of the Grid Size S setup failure:
    - English Google Flow labels tile sizes as `S` (Small), `M` (Medium), `L` (Large).
    - Indonesian Google Flow localizes tile sizes to `K` (Kecil), `S` (Sedang), `B` (Besar).
    - In German it is `K / M / G`, French `P / M / G`, Japanese/Chinese `小 / 中 / 大`.
    - Querying `span:has-text("S")` in Indonesian matched the **Sedang (Medium)** toggle instead of Small! In locales lacking the letter "S", the query failed completely.
- **Structural Positional LTR Indexing for Tile Size (`findGridSizeToggle`):**
  - Implemented `findGridSizeToggle(size = 'S', pane = document)` in `FlowSettingsService.js`.
  - Targets the 3-button `mat-button-toggle-group` without `mat-icon` in `flow-tile-view-settings` (distinguished from the 2-button layout mode group with `dashboard` and `campaign_all` icons).
  - Sorts toggles by screen coordinate (`getBoundingClientRect().left`) to guarantee exact LTR index across all locales:
    - `index 0` = Small (`S` in EN, `K` in ID, `P` in FR, `小` in JA/ZH).
    - `index 1` = Medium (`M` in EN, `S` in ID, `M` in FR, `中` in JA/ZH).
    - `index 2` = Large (`L` in EN, `B` in ID, `G` in FR, `大` in JA/ZH).
  - Updated `SELECTORS.GRID_SIZE_S_TOGGLE`, `GRID_SIZE_M_TOGGLE`, and `GRID_SIZE_L_TOGGLE` in `FlowDOM.js` using modern CSS pseudo `:not(:has(mat-icon)) mat-button-toggle:first-of-type button`.
- **Clear Prompt Switch Material Ligature Icon Fallback (`ink_eraser`):**
  - Enhanced `findClearPromptSwitch(pane)` in `FlowSettingsService.js` to look for `button[name="clear-prompt-on-submit"]` first (standard programmatic attribute), followed by Material Symbols ligature `ink_eraser` (universal glyph name across all languages).
- **Video Duration Numerical Token Matching (`selectDuration`):**
  - Indonesian localizes seconds to `dtk` (e.g. `10 dtk`, `8 dtk`, `6 dtk`, `4 dtk`) whereas English uses `s` (e.g. `10s`, `8s`, `6s`, `4s`).
  - Updated `selectDuration(duration)` to extract numerical digits (`numMatch = String(duration).match(/\d+/)`) and match buttons whose text contains or starts with the number (`8s`, `8 dtk`, `8`), ensuring seamless multi-locale compatibility.
- **Video Ingredients Ligature Icon Alignment (`chrome_extension`):**
  - Updated `selectMediaMode` in `FlowSettingsService.js` to prioritize Material Symbols ligature `chrome_extension` (the exact glyph Google Flow renders for Ingredients/Bahan). Added positional fallbacks (`mat-button-toggle:nth-of-type(1)` for Ingredients, `nth-of-type(2)` for Frames).
